# Inbox Triage Playbook

1. Use the `browser` tool (or relevant email-fetching capability if available) to navigate to the user's webmail (e.g., https://mail.google.com/ or https://outlook.live.com/).
2. If you hit a login wall, ask the user to log in, end your turn, and wait. Once they log in, proceed.
3. Review the most recent emails (e.g., top 10-20 from the last 24-48 hours).
4. Ignore newsletters, automated alerts, shipping updates, calendar invites, and marketing.
5. Identify emails from actual humans that require a reply or a decision from the user.
6. Summarize the important emails. For each one:
   - Who it's from.
   - What they want.
   - A brief suggestion on how the user might reply.
7. Present the summary to the user clearly. If no emails require attention, report "Inbox is clean. No replies needed."
