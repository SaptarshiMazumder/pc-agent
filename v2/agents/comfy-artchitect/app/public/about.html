About Comfy Penguin

Last updated 22 September 2026

Comfy Penguin designs, runs and repairs ComfyUI workflows — on a GPU machine we rent for you, for as long as you are using it.

You describe what you want to generate. The agent rents a GPU machine running ComfyUI on your behalf, installs the models the job needs, reads what is actually on that machine — the checkpoints, the custom nodes, the samplers — builds a graph against that, submits it, reads whatever the server rejects, fixes it, and runs it again until the result is right. You get back the images, the workflow file importable into ComfyUI like any other, and an installer script that sets the same thing up on a ComfyUI of your own.

Why it works against a real machine

Every ComfyUI install is different. A tool that writes workflows from memory names checkpoints that exist on its author's machine and wires last year's model families the way they used to work. Comfy Penguin reads the machine in front of it before it writes anything, which is the difference between a workflow file and a workflow that runs.

The machine is rented from the Vast.ai GPU marketplace when a conversation needs one, one machine per account, and destroyed again after about ten minutes without activity. You can open the ComfyUI running on it from the app while it is up. Nothing is kept on it: model files are downloaded fresh each time, and every image it renders is copied back to your workspace with us before the machine goes away.

What you pay for

You buy credits, in packs of US$5, US$10 and US$20. Credits are spent on three things: the AI model calls the agent makes while it is reasoning, researching and repairing your graph; the GPU machine, charged by the minute at the marketplace's own hourly rate for as long as it is up, with no markup from us; and any paid hosted model the agent uses on your say-so, at the price it shows you before it asks. Credits are drawn down as you use them, at the rates shown in the app; nothing is charged on a schedule and there is no subscription to cancel.
